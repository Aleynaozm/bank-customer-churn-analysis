# Bank Customer Churn Analysis

End-to-end analysis of why bank customers leave, and a model that predicts who will leave next.

## Goals
- Explore churn drivers with SQL (PostgreSQL) and Python
- Build an explainable churn prediction model (XGBoost + SHAP)
- Present insights in an interactive Streamlit dashboard

## Project Structure
data/        raw data (not tracked)
sql/         SQL analysis queries
notebooks/   EDA and modeling
src/         reusable Python code
dashboard/   Streamlit app
